# 2026-SENSU

## SENSUとは
**SENSUは、話したい「ネタ」を記録しておくためのアプリです。**

これ、友達に話したら面白そうと思ったのに、いざ話すときには忘れている。  
逆に、友達と話していて「何か面白い話ないかな」と考えてしまう。  
そんな経験から、話したいネタを記録して、必要なときに思い出せる場所としてSENSUを作っています。

### 名前の由来
SENSUという名前には、2つの意味を込めています。
### 扇子
昔の「**ネタ帳**」としての扇子から。  
話芸の世界では扇子が小道具として使われてきました。  
「ネタを持ち歩く」というSENSUの役割と重ねています。

### センス
「**面白いネタを思いつくセンス**」から。  
日常の中でふと思いついたことや、誰かに話したくなったことを、自分のセンスとしてストックしていく。

### SENSUは、ネタとセンスを持ち歩くアプリです。

## セットアップ

### 1. 仮想環境を作成

```bash
python3 -m venv .venv
```
### 2. 仮想環境を有効化
```bash
source .venv/bin/activate
```

### 3. 必要なパッケージをインストール
```bash
pip install -r requirements.txt
```

### 4. Djangoのマイグレーション
```bash
python manage.py migrate
```

### 5. 開発サーバーを起動
```bash
python manage.py runserver
```
