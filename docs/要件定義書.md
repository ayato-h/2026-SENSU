# 要件定義書

## 1. プロジェクト概要
**SENSUは、話したい「ネタ」を記録しておくためのWebアプリです。**

## 2. 開発の目的・背景
```text
 これ、友達に話したら面白そうと思ったのに、いざ話すときには忘れている。   
 逆に、友達と話していて「何か面白い話ないかな」と考えてしまう。  
 そんな経験から、話したいネタを記録して、必要なときに思い出せる場所としてSENSUを作っています。

名前の由来
 SENSUという名前には、2つの意味を込めています。

扇子
 昔の「ネタ帳」としての扇子から。  
 話芸の世界では扇子が小道具として使われてきました。  
「ネタを持ち歩く」というSENSUの役割と重ねています。

センス
「面白いネタを思いつくセンス」から。  
　日常の中でふと思いついたことや、誰かに話したくなったことを、自分のセンスとしてストックしていく。
```
関連情報：[README : SENSUとは](../README.md#sensuとは)

## 3. 想定ユーザー
友達との会話を楽しみたい一方で、話題が思い浮かばなかったり、思いついた話のネタを忘れてしまったりする人を想定する。

特に、日常生活の中で面白いことや誰かに話したいことを思いついても、

いざ話そうとしたときには忘れてしまう人や、会話中に話題がなくなり、何を話せばよいか困ってしまう人を対象とする。

SENSUを通じて、日常で思いついた話のネタを記録・整理し、必要なときに振り返れるようにすることで、

会話の話題に困る場面を減らし、友達との会話をより楽しめるようになることを目指す。

## 4. システムの概要
本システムは、日常で不意に起こる誰かに伝えたい大きな出来事から、時間が経つと忘れてしまいそうな些細な話題まで、

会話のネタとして記録・管理できるWebアプリケーションである。

ユーザーは、思いついたネタの名前や詳細な内容を登録すると同時に、❀✿を用いた5段階の自己評価を設定し、話したいネタの優先順位を決めることができる。

これにより、日常で思いついたネタを蓄積し、必要なときに優先度の高いネタを素早く見つけられるようにする。

ネタを誰かに話す機会につなげることで、会話の話題に困る場面を減らし、友達との会話をより楽しめるように支援する。

## 5. 機能要件

| 機能 |　内容 |
|:---|:--- |
| [ネタ登録機能](#ネタ登録機能) | ネタの名前、詳細な内容、5段階の自己評価を登録できる。 |
| [ネタ一覧表示機能](#ネタ一覧表示機能) | 登録したネタを一覧で確認できる。 |
| [ネタ編集機能](#ネタ編集機能) | 登録済みのネタの内容や自己評価を変更できる。 |
| [ネタ削除機能](#ネタ削除機能) | 登録済みのネタを削除できる。 |
| [古扇子機能（FULL SENSU）](#古扇子機能full-sensu) | 削除したネタも含め、過去に登録したネタを振り返ることができる。 |
| [評価順表示機能](#評価順表示機能) | 自己評価の高さに応じて、ネタを並べ替えて表示できる。 |
| [経過日数表示機能](#経過日数表示機能) | ネタの登録日を0日目として、登録からの経過日数を確認できる。 |
| [保存件数制限機能](#保存件数制限機能) | 登録できるネタの件数を最大7件に制限する。 |

### ネタ登録機能
ネタの名前、詳細な内容、5段階の自己評価の項目はすべて入力必須とする。  
必須項目が入力されていない場合は、登録できないようにする。  
自己評価は5段階とし、初期値は3とする。

### ネタ一覧表示機能
登録済みで削除されていないネタを一覧で表示する。  
表示順は登録日の古い順とする。  
登録日の古いネタから順番に振り返ることで、登録したネタを実際の会話で使う習慣につなげる。

### ネタ編集機能
編集後も、元の登録日を保持する。

### ネタ削除機能
削除したネタは通常の一覧には表示せず、古扇子機能（FULL SENSU）から確認できるようにする。

### 古扇子機能（FULL SENSU）
削除済みのネタも表示対象とし、過去に記録したネタを一覧で振り返ることができる。

### 評価順表示機能
登録済みで削除されていないネタを、自己評価の高い順に表示できる。  
同じ評価のネタは、登録日の古い順に表示する。

### 経過日数表示機能
ネタの登録日を0日目として、登録日と当日の日付の差に基づいて経過日数を表示する。  
登録日当日は0日、翌日は1日として計算する。

### 保存件数制限機能
保存できるネタの上限を7件とする。  
登録済みで削除されていないネタが7件ある場合、新しいネタの登録を制限し、既存のネタを削除するよう案内する。  
削除によって保存件数が7件未満になった場合、新しいネタを登録できる。

## 6. 画面要件

本システムは、スマートフォンでの利用を前提としたWebアプリケーションとする。

ユーザーが必要なときに話したいネタを瞬時に把握できるよう、UIをシンプルにし、画面移動を最小限に抑えた構成とする。

| 画面名 |　内容 |
|:---|:--- |
| ホーム画面 | 	登録済みのネタ一覧を表示する。 |
| ネタ詳細画面 | 選択したネタの詳細な内容を確認する。 |
| ネタ編集画面 | 登録済みのネタの内容や自己評価を変更する。 |
| ネタ登録画面 | 新しいネタを登録する。 |
| 古扇子画面（FULL SENSU） | 削除したネタを含む、過去に登録したネタを振り返る。 |
| アカウント・設定画面 | アカウントに関する情報や各種設定を管理する。 |

```text
ホーム画面(ネタ一覧)
 ├─ ネタ詳細画面
 │   ├─ 編集画面
 │   │   └─ 保存 → ネタ詳細画面
 │   └─ 削除 → ホーム画面
 │       
 │
 ├─ ネタ登録画面
 │   └─ 登録 → ホーム画面
 │
 ├─ 古扇子画面（FULL SENSU）
 │   └─ 過去のネタ詳細画面
 │
 └─ アカウント・設定画面
```
