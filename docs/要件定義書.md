# 要件定義書

## 1. プロジェクト概要
**SENSUは、話したい「ネタ」を記録しておくためのWebアプリです。**

## 2. 開発の目的・背景

```text
 これ、友達に話したら面白そうと思ったのに、いざ話すときには忘れている。   
 逆に、友達と話していて「何か面白い話ないかな」と考えてしまう。  
 そんな経験から、話したいネタを記録して、必要なときに思い出せる場所としてSENSUを作っています。

名前の由来
 SENSUという名前には、2つの意味を込めています。

扇子
 昔の「ネタ帳」としての扇子から。  
 話芸の世界では扇子が小道具として使われてきました。  
「ネタを持ち歩く」というSENSUの役割と重ねています。

センス
「面白いネタを思いつくセンス」から。  
　日常の中でふと思いついたことや、誰かに話したくなったことを、自分のセンスとしてストックしていく。
```
関連情報：[README : SENSUとは](../README.md#sensuとは)

## 3. 想定ユーザー

友達と話すことは好きだが、会話の中で話題が思い浮かばず、何を話せばよいか困ってしまう人。

特に、自分の話に自信がなく、会話を盛り上げられないことや、話が途切れてしまうことに不安を感じている人を想定する。

SENSUを通じて、日常で思いついた話のネタを記録・整理し、必要なときに振り返ることで、会話の話題に困る場面を減らす。
これにより、自分の話に自信を持ち、友達との会話をより楽しめるようになることを目指す。
