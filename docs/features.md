# Features

## 1. SENSUとは

SENSUは、話したい「ネタ」を記録しておくためのアプリです。

これ、友達に話したら面白そうと思ったのに、
いざ話すときには忘れている。

逆に、友達と話していて
「何か面白い話ないかな」と考えてしまう。

そんな経験から、話したいネタを記録して、
必要なときに思い出せる場所としてSENSUを作ります。

## 2. コンセプト

「ネタとセンスを持ち歩く」

## 3. 解決する課題

- 思いついたネタを忘れてしまう
- 後で話そうと思ったことを思い出せない
- 友達と話すときに話題が思いつかない
- 過去に思いついたネタを活用できていない

## 4. 基本機能

- ネタを登録する
- ネタを見る
- ネタを編集する
- ネタを削除する
- ネタを検索する
- ...
